# Beyond Words - Privacy Policy

Last updated: 25 October 2026

Beyond Words is a personal YouTube channel. This page covers the small private tool ("Beyond Words Automation") its owner uses to manage that channel.

## What the tool does
- Uploads and schedules videos on the owner's own YouTube channel.
- Reads the owner's own channel statistics (views, watch time, subscribers) to write a monthly report.

## What data it uses
- It only accesses the Google account of the channel owner, who authorizes it personally.
- Data is stored only on the owner's own computer.
- No data is sold, shared, published, or given to any third party.
- The tool is not offered to the public and has no other users.

## Google API Services
The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
The owner can revoke access at any time at https://myaccount.google.com/permissions
